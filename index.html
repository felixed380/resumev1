🚗 Urban Routes — E2E Automation with Selenium

End-to-end test automation in Python

Automated end-to-end test that simulates a complete user booking flow on Urban Routes (ride-hailing web app): from entering origin/destination, selecting a fare, confirming phone via SMS, registering a payment method, to customizing the ride with a driver message and extra items. Built with Page Object Model for maintainability.

284 Lines of code
7 Flow steps
5 Tech techniques
100% Pass rate
Flow covered:
  • 📍 Origin & destination input
  • 🚕 Taxi request + "Comfort" fare selection
  • 📱 Phone number confirmation via SMS code (extracted from network logs via CDP)
  • 💳 Payment method registration
  • 💬 Driver message + extra items (blanket, tissues, ice cream counter)
Advanced techniques:
  • 🏗️ Page Object Model (POM) — separation of page logic from test logic
  • ⏱️ WebDriverWait + Expected Conditions — handling async React loading
  • 🌐 Chrome DevTools Protocol — intercepting network responses for SMS code
  • 🎯 execute_script & switch_to.active_element — interacting with hidden/0px elements
  • ⌨️ Keys.TAB (blur) — triggering form validations naturally
